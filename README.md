# African Swine Fever ENM Project – Portable Layout

## Quick-Start
1. Open the project folder in RStudio.
2. Run the pipeline:
   ``r
   source(file.path("code", "pipeline", "ASF_ENM_COMPLETE_PIPELINE.R"))
   ``
3. Generate the publication-ready figures:
   ``r
   source(file.path("code", "figures", "generate_publication_figures.R"))
   ``
All outputs will appear under output/.
